4. 推荐方案：随机子采样（不依赖款式标签）Recommended: label-free random sub-sample

既然 MG 没有款式标签，最稳妥也最省事的就是从 8644 ep 均匀随机抽 ~1500 ep（用 episode_sampling_rate 或 episode 过滤）。因为 MG 本身按 layout×style 近似均匀生成，均匀随机抽样天然就覆盖各款——不需要显式分层。难款会因为"全局多样性提升"被动受益。
Since MG has no style label, just uniformly sample ~1500 of 8644 eps. MG is generated near-uniformly across styles, so random sampling covers all styles for free — hard styles benefit from the global diversity boost.

4.1 进阶：真要"偏袒难款"的两条路 If you insist on hard-style weighting

路径做法代价
路径① 重放标注
replay-label		 逐条重放 MG demo 初始状态进 robocasa 读 layout_id，给 8644 ep 打款式标签，再按难度加权 准确，但一次性 ~数小时重放（8644 ep）
路径②（推荐）课程式两轮
curriculum		 先随机子采样训一版 → benchmark 看哪些 seed/layout 仍失败 → 第二轮只补这些难 layout 的 human/MG demo（target split 的款式可控） 无需给 MG 全量打标；用评测结果驱动，自然"偏袒难款"
结论 Bottom line：先用 §4 随机子采样（最省事、覆盖全），把 N1.7 拉一波；若仍有几款顽固失败，再用路径②课程式定点补这些款——这比一开始就给 8644 ep 打标签实际得多。
Start label-free random; if specific styles stay stuck, do a curriculum second round targeting them. More practical than labelling all 8644 up front.

4.2 两种混训配方 Two recipes

配方做法优点缺点
A 混合单阶段 MG 子集 + human 拼一个数据集，一次训 ~40k step 最简单；复用现有 watchdog；一次出结果 MG(pretrain) 与 human(target) 分布混合，可能稀释 target 精度
B 两阶段（官方配方） ① MG 子集预训练 → ② human target 微调（少 step） GR00T 官方推荐；广度打底 + target 精修 两段流程，多一次配置
推荐 A 起步：单阶段最简单、能复用现有 watchdog，先验证"加 MG 是否提升"。若 A 有效但 target 精度被稀释，再升级 B。
Start with A to validate the lift; escalate to B only if target precision gets diluted.
